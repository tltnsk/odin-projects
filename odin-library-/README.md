# Book Library – The Odin Project

A simple, clean book library app built with HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/). This project allows users to add and manage their personal book collection in the browser.

---

## Features

- Add books with:
  - **Title**
  - **Author**
  - **Number of Pages**
  - **Read Status**
- Toggle read/unread status
- Remove books from your library

---

## Design Choices

- **Minimalist layout**: Clean, distraction-free interface
- **Color scheme**: Carefully selected shades of blue 
- **Typography**: Google Fonts for a modern look

---

## Built With

- HTML5
- CSS3
- JavaScript
